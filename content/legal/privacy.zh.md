Jerbix（下称“我们”）运营 [www.jerbix.site](https://www.jerbix.site)。本政策说明你浏览网站、注册账号、购买源码产品或联系我们时，我们如何处理个人信息。对于你自行部署的 Jerbix 源码项目，其运营者应另行制定自己的隐私政策；本政策不替代该项目的隐私说明。

## 我们收集哪些信息

我们根据你使用的功能处理以下信息：

- **账号信息**：邮箱、昵称、邮箱验证状态，以及创建和更新时间。密码以哈希形式存储，不以明文保存。
- **登录与安全信息**：会话标识、登录时间、会话有效期，以及登录会话关联的 IP 地址和浏览器／设备信息。使用 API key 时，还会处理密钥标识、权限及使用记录；请自行妥善保存密钥。
- **订单与支付信息**：购买者账号、产品与价格标识、金额、币种、付款状态、支付服务商的客户及交易标识，和处理售后所需的信息。支付资料由 Stripe 在其支付页面处理，我们不接收或存储你的完整银行卡号或安全码。
- **邮件与支持信息**：验证邮件、密码重置、欢迎邮件所需的收件邮箱、昵称和操作链接，以及你主动通过支持邮箱发送的内容和订单资料。
- **网站运行信息**：网络请求中通常包含的 IP 地址、访问路径、时间及技术错误信息，用于网站交付、安全防护和故障排查；基础设施服务商也可能为这些目的处理请求信息。

当前本站未启用广告追踪、第三方访问统计、营销邮件订阅或用户文件上传。向支持邮箱发送附件时，请避免提供与问题无关的个人信息、密码或完整支付资料。

## 我们如何使用信息

我们使用上述信息提供账号及购买服务，包括验证邮箱、维持登录、重置密码、确认订单、交付源码、提供更新与支持、处理退款和回应咨询；也用于防范欺诈与滥用、保障服务安全、排查故障，以及履行依法适用的财务、税务或其他义务。

在需要确定处理依据的适用法律下，处理依据包括履行与你的交易或按你的要求采取交易前措施、遵守法定义务，以及维护服务安全和回应咨询的合法利益。只有需要并取得有效同意时，才以同意作为相应处理依据；你可撤回该同意，不影响撤回前处理的合法性。

我们不出售个人信息，不把账号或订单资料用于与上述目的无关的广告画像。验证、密码重置和订单服务邮件属于功能或交易邮件。

依法需要、保护用户及服务的合法权益，或处理组织／资产转移时，我们可能在必要范围内披露信息；如法律要求，会采取相应通知和保护措施。我们不会向不相关的第三方任意提供你的账号资料。

## 数据存储、跨境处理与保留

服务商的基础设施可能位于你所在地区之外，因此信息可能在其他国家或地区存储或处理。我们通过服务商的合同及可用的数据保护安排管理这类处理；适用法律要求额外保障时，须采取相应措施。你可联系我们了解与你相关的处理情况。

账号资料通常在账号存续期间保留，用于持续提供服务。会话、验证凭据和安全记录按有效期、账号安全及排查问题所需期限保留；部分记录到期失效后可能等待清理，并不表示届时已从所有存储中立即删除。支持邮件按解决问题、后续服务与处理争议所需期限保留。

订单、退款及相关记录按履行交付、支持、财务／税务义务和处理争议所需期限保留。账号删除不一定同步删除依法必须保留的交易记录；这类记录应限制用途和访问。备份、副本或服务商记录按其适用的清理周期处理。我们不承诺所有数据在账号删除瞬间即从所有系统消失；如需了解特定记录的保留依据或申请清理，请联系我们。

## Cookie 与浏览器存储

本站使用维持登录、安全及偏好设置所需的 Cookie 和浏览器存储，包括：

| 类别 | 名称或形式 | 用途与期限 |
|---|---|---|
| 认证与安全 | Better Auth 会话 Cookie，例如 `better-auth.session_token`，HTTPS 下可能带 `__Secure-` 前缀；认证流程还可能使用临时 Cookie | 验证会话、防护认证流程；以会话或相应 Cookie 的有效期为准，退出登录或撤销会话会使相关会话失效 |
| 语言 | `NEXT_LOCALE` | 记住语言选择，切换语言写入时有效期为一年，可由浏览器清除 |
| 外观与布局 | `THEME`、`DOCS_SIDEBAR`，以及相关界面的本地偏好存储 | 保存主题及文档侧栏偏好，直至有效期届满、被覆盖或你清除浏览器数据 |

本站未启用广告或统计追踪 Cookie。Stripe 等第三方在其自己的页面可能使用支付安全所需的 Cookie，详见其政策。你可在浏览器中查看、阻止或清除存储；阻止必要 Cookie 可能使登录和偏好设置无法正常工作。

## 你的选择与权利

你可在个人中心修改昵称、在安全页面修改密码或申请删除账号，并在登录设备页面撤销会话。当前邮箱没有自助修改入口；如需更正邮箱，请通过支持邮箱联系，我们会先核实身份和可行的处理方式。

根据适用法律，你可能享有访问、更正、删除、获取副本或可携带数据、限制处理、反对处理及撤回同意的权利，也可向有权受理的监管机构投诉。请通过本页邮箱提出请求。我们会进行合理的身份核验，并在适用法律规定的期限内答复；涉及法定保留义务或他人权利时，部分请求可能受到限制，我们会说明原因。

我们使用密码哈希、会话校验和访问控制等措施保护信息，但任何网络或存储系统都无法保证绝对安全。请保管好自己的密码、验证链接和 API key，不要通过普通支持邮件发送这些凭据。

本站面向具有相应法律行为能力的产品购买者与开发者，不以儿童为服务对象。如果你认为儿童在未经适当授权的情况下向我们提供了个人信息，请联系我们处理。

我们会在本页公布政策更新及生效日期；涉及处理目的或用户权益的重大变更，会根据情况通过站内或注册邮箱通知，并依法取得需要的同意。
