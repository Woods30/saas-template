## 页面内容与交互

1. 首屏左侧 Slogan、两行标题、定位和受众文案。主按钮到 #pricing，次按钮到当前语言文档中心。权益为全部源码、永久支持、免费升级。
2. B 动效左侧配置源码，右侧同步变化。0ms 模板、850ms 品牌、1800ms 页面、3000ms 部署提示、6000ms 重启。部署仅为说明支持 Cloudflare 的示意。默认循环，支持暂停、恢复和重播。后台停止定时器，减少动态效果时显示最终状态，卸载清理定时器和监听。
3. 三个价值点：最佳实践、低门槛、源码自由定制。
4. 功能涵盖 SEO、认证、支付、API Key、邮件、多语言、营销页面、文档、通知，以及存储、Cloudflare 等已有能力，更多模块持续加入。内置中英可扩展更多语言。当前内置 Stripe，更多支付服务商后续增加。
5. 复用技术栈和启动流程，强调 Cloudflare 免费额度起步与一条命令部署，说明仍需资源和服务配置。
6. 模板单价 $99 USD，一次性购买，全部源码、永久支持、免费升级；移除首页演示套餐概览。保留 #pricing、#features、#workflow、#faq。品牌故事为次要内容。
7. FAQ 保持真实，兼顾受众、数据库、配置、定制与升级。不虚构用户、性能与上线时长。

## 实施判断与边界

- 首页模板复用现有 Checkout，websiteConfig.template 配置 priceUsd=99、productId=template、offerId=once；products.ts 的独立 lookup_key 为 jerbix_template，不复用资源包。服务端强制验证 USD 99 一次性价格，缺失或不匹配则拒绝结账。不创建或调整远程 Stripe 商品。
- 未登录购买进入当前语言登录页，切换注册及邮箱验证均保留安全站内回跳；完成后回到首页价格区点击购买。验证邮件先落到验证结果页以显示失败原因。取消 Checkout 回价格区，成功回账单。导航“模版内容”改为“价格”。
- 首页移除 Stripe catalog loader，纯营销页独立渲染。定价统一在首页 #pricing；旧 /pricing 仅跳转当前语言首页价格区，不加载演示套餐，不收录 sitemap。账单与功能页价格链接直接指向首页价格区，支付接口保持原有协议。
- 原有 LandingPage 直接更新，首屏动效拆出 SourceProductDemo，保留内部暂停和重播。链接使用上游 buttonVariants 样式，操作使用 Button，不扩展共享 Hero 接口。
- docs 关闭时，文档 CTA 回退 #features；价格展示独立于 payment.enabled，auth 或 payment 关闭时禁止购买。
- 手动暂停与后台隐藏保留当前周期已过时间，恢复从暂停处继续。切回前台不解除手动暂停。重播明确清零进度并解除暂停。减少动态效果优先，静态展示终态且不计时。
- 使用已有 Button 等上游组件与语义 token。不增加依赖，不改 ui/，不手改生成物。
- 不提交、推送、部署，不操作远程支付资源或生产数据库。
